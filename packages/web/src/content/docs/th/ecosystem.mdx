ชุดโครงการชุมชนที่สร้างขึ้นบน OpenCode

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ OpenCode ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-igris](https://github.com/awesome-igris/awesome-igris) และ [igris.cafe](https://igris.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
